# Smart Roster Management System

Simple Streamlit app for employee roster planning across brands, processes, and pods.

## Features
- 30 sample employees, 20 brands, 3 pods
- Employee and brand views
- Sample allocation data
- Weekly offs and leave entries
- Monthly roster generator
- Basic issue validation
- CSV export

## Run locally
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
